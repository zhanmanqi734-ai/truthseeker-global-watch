# 真探 TruthSeeker · 国际新闻涉华舆情监测

> 在这里瞭望世界，在这里探索真相。

[打开在线监测看板](https://truthseeker-global-watch.zhanmanqi734.chatgpt.site/)

真探 TruthSeeker 是面向国际新闻观察与事实核查选题的项目。本网站聚合海外媒体公开 RSS 中与中国有关的报道线索，以北京时间组织每日监测报告，帮助编辑和研究者更快地发现值得阅读原文、核对数据和追踪当事方回应的议题。

网站提供的是**线索发现与初步整理**，不是自动判定新闻真伪的工具。报道的叙事倾向、待核查信息点和优先分都需要结合原文及一手证据人工复核。

## 为什么开发这个项目

国际新闻中的涉华议题更新快、来源分散，人工逐站浏览容易遗漏报道，也难以迅速比较不同媒体的表述。真探工作室希望把“发现报道—整理线索—确定核查重点”放在一个可检索的工作台中：保留原始出处，提供英中对照，标明分析依据和不确定性，让团队把时间更多地用在深入阅读、证据核对与内容生产上。

本项目适用于国际新闻值班、涉华舆情观察、事实核查选题、跨媒体报道比较及新闻传播研究。它不替代记者调查、专业翻译或独立的事实核查结论。

## 在线看板能做什么

| 功能 | 当前实现 |
| --- | --- |
| 滚动监测与日报 | 通过公开 RSS 采集；运行中的报告合并既有报道，北京时间每天 08:00 归档前一监测窗口，并可选择历史日期。 |
| 涉华报道筛选 | 在 RSS 标题或摘要中查找 `China` / `Chinese`，过滤明显广告并按报道链接去重。 |
| 重点话题与核查线索 | 按时效、相近标题的跨站提及及文本线索计算选题优先分，展示重点话题、报道列表和待核查信息点。 |
| 英中对照 | 采集后尝试翻译 RSS 标题和摘要，将英文与中文字段一同保存；页面读取已存内容，支持人工校订。 |
| 分类与分析 | 标记军事、时政、社会、经济、科技、环境、体育、文化等话题，提供正面、中性、负面语境标签及核查建议。 |
| 检索与溯源 | 按关键词、媒体、话题、倾向筛选，按优先分、时间、跨站提及排序；详情可打开媒体原文。 |

### 监测范围与时间

当前代码配置了 16 个 RSS 信源：BBC News、The Guardian、The Washington Post、Al Jazeera、Deutsche Welle、France 24、Euronews、NPR、Financial Times、Nikkei Asia、The New York Times、South China Morning Post、Sky News、Voice of America、CBC News 和 The Conversation。各媒体的实际可用性与 RSS 覆盖范围可能变化，可在网站的“媒体信源”页查看本轮状态。

完整日报的时间窗口为**北京时间前一日 08:00（含）至当日 08:00（不含）**。08:00 之后的滚动采集更新下一期“进行中快照”；页面上的报告日期可能指向次日 08:00 将归档的那一期。网站另设手动运行入口，定时任务及当前运行状态以在线部署为准。

## 使用方法

1. 打开[在线看板](https://truthseeker-global-watch.zhanmanqi734.chatgpt.site/)。页面打开时会读取数据库中最近的一期报告；若一直保持页面开启，请刷新浏览器查看后续更新。
2. 在“每日舆情”查看监测时间、报道总量、重点话题榜与涉华报道列表。用搜索框及筛选器缩小范围，或切换排序方式。
3. 在“核查线索”寻找需要进一步查证的报道。进入条目详情，阅读标题和 RSS 摘要的英中对照、话题分类、语境标签、具体待核查点与建议的原始资料入口。
4. 点击“打开媒体原文”，核对完整报道、作者、发布时间、原始引述、数据来源及后续更正。不要仅凭 RSS 摘录或本站标签下结论。
5. 在“媒体信源”查看各站采集状态；使用报告日期选择器回看历史报告。需要核对当天新变化时，刷新页面并查看“最近生成”时间。

页面上的“立即运行监测”和译文校订会写入网站数据。目前公开部署尚未为这些写入操作建立独立的角色权限，**请仅由获得维护授权的人员使用**。

## 一条报道是怎样进入看板的

1. 读取媒体公开 RSS 条目及其标题、摘要、链接和发布时间。
2. 按北京时间窗口、关键词和广告特征过滤，规范化链接并去重；滚动采集沿用已保存的报道与译文。
3. 依据标题和摘要识别话题、叙事倾向及待核查线索；配置模型密钥时可进行模型辅助研判和中文摘要，未配置时明确标记为“规则初筛”。
4. 在采集阶段尝试翻译并保存英文原文与中文译文。翻译失败会记录状态、保留英文，并在后续采集中重试。
5. 计算选题优先分、汇总跨站相近标题，保存报道及日报，供网页读取。

“跨站提及”基于标题相似度近似计算；“优先分”是内部选题排序指标，**不是社交平台热度、媒体阅读量，也不是报道可信度分数**。

## 如何理解结果与已知限制

- **只覆盖 RSS 可见内容。** 本站保存的是订阅条目的标题与摘要，不抓取或展示媒体全文；并不保证收齐媒体网站在该时段发布的所有报道。全文请访问原始链接，原文版权归各媒体所有。
- **标签不是真伪结论。** “负面语境”描述报道措辞倾向，不表示报道失实；“待核查”表示值得核对的主张，也不表示该主张已被证伪。规则初筛可能误判，跨站相似报道不等于相互独立的证据。
- **中文译文可能缺失或有误。** 当前翻译使用无需本站 API 密钥的免费服务，受网络与服务限额影响；失败时保留英文并显示异常状态。重要事实、数字、专有名词和引述应以英文原文及一手资料为准。
- **模型能力取决于部署配置。** 没有配置模型密钥时，中文精简摘要和研判不能被描述为已完成 AI 深度核查；请留意每期报告的“规则初筛 / AI”标记。
- **报告更新取决于任务成功。** 信源中断、RSS 滚动、翻译限额或任务故障会影响覆盖与时效。请查看报告生成时间和信源状态；上次成功保存的数据不代表此刻已完成新一轮采集。
- **网站当前是公开访问。** 页面显示的“仅限内部使用”是使用提示，不是访问控制。公开链接可被其他人打开；写入接口尚需增加身份验证和权限分级，不能将当前版本当作安全的多人后台。

## 技术与仓库说明

项目使用 React、TypeScript、Vinext/Vite 与 Cloudflare Worker 运行环境；采集与处理流程使用 LangGraph，RSS 由 `fast-xml-parser` 解析，报告和条目保存在 Cloudflare D1。主要代码位于 `app/`（界面与 API）、`lib/pipeline.ts`（采集、过滤、研判、翻译和排序）、`lib/store.ts`（持久化）、`db/` 与 `drizzle/`（数据结构）。

此公开仓库**只包含源码，不包含线上数据库、历史报告或部署密钥**。源码中的 Sites/Cloudflare 绑定配置依赖原托管环境；仓库未提供可直接运行的独立部署配置。直接导入 Vercel不能保持当前数据库与定时任务工作，迁移前需要改造运行环境、持久化存储、定时任务与写入接口权限。请勿把真实密钥、数据库导出或内部资料提交到公开仓库。

仓库目前没有附带开源许可证；公开可见不等于授予复制、修改或再发布许可。媒体报道的版权及使用条件以各原始来源为准。
